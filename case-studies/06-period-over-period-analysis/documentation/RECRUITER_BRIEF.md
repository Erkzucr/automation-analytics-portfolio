# Recruiter Brief: Period-Over-Period Analysis

**Short version:** Automated current-versus-prior comparison that flags unusual movements instead of requiring someone to eyeball two periods side by side.

**Situation:** Recurring outputs need a current-versus-prior comparison, and doing that consistently by hand is hard to sustain.

**Task:** Build a comparison that's consistent regardless of who's running it that month.

**Action:** Calculated current values, joined prior-period values, and applied a threshold to separate normal movement from anything that needs review.

**Result:** A repeatable movement-analysis pattern, with the math visible in the supporting output, not just a flag.
