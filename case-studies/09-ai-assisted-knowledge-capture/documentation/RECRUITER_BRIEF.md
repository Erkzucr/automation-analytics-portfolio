# Recruiter Brief: AI-Assisted Knowledge Capture

**Short version:** Using AI to draft process documentation faster, while keeping a real verification and human-review step so the draft doesn't get mistaken for the final word.

**Situation:** Process knowledge gets documented inconsistently depending on who's writing it up.

**Task:** Use AI to speed up drafting without letting accuracy slip.

**Action:** Drafted from a transcript using a standard prompt, verified the draft against source line by line, routed anything unverified to human review, and versioned the final output.

**Result:** A documentation pattern that's faster to produce than manual writeups, with the verification step built in rather than assumed.
