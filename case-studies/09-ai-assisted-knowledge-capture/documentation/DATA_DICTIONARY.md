# Data Dictionary

| Field | Meaning | Example |
|---|---|---|
| record_id | Unique key for a transcript segment or draft item | REC00001 |
| period_key | Version or draft cycle | P01 |
| dimension_a | Topic or section grouping | DA001 |
| dimension_b | Secondary grouping attribute | DB001 |
| category_code | Content category | CAT01 |
| value_amount | Synthetic value used to demonstrate control totals | 1250.00 |
| status_code | Verification or review status | VALID |
