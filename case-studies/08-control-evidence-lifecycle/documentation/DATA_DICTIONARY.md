# Data Dictionary

| Field | Meaning | Example |
|---|---|---|
| record_id | Unique key for a control execution record | REC00001 |
| period_key | Period the control was executed in | P01 |
| dimension_a | Control owner or grouping attribute | DA001 |
| dimension_b | Secondary grouping attribute | DB001 |
| category_code | Control category | CAT01 |
| value_amount | Synthetic value tied to the execution | 1250.00 |
| status_code | Evidence or certification status | VALID |
