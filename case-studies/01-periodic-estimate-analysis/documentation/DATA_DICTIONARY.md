# Data Dictionary

Field reference for the sample input files. Everything is synthetic, so the "meaning" column describes the role each field plays in the workflow rather than any real-world source system.

| Field | Meaning | Example |
|---|---|---|
| record_id | Unique key for the row | REC00001 |
| period_key | Which period the record belongs to | P01 |
| dimension_a | Grouping attribute used for aggregation | DA001 |
| dimension_b | Second grouping attribute | DB001 |
| category_code | Category used to apply calculation logic | CAT01 |
| value_amount | Randomly generated demo value | 1250.00 |
| status_code | Processing status assigned during validation | VALID |
