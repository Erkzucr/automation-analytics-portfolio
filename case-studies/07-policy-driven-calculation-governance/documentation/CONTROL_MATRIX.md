# Control Matrix

Maps each control objective to the procedure that enforces it and the evidence it produces.

| ID | Objective | Procedure | Evidence |
|---|---|---|---|
| CTL-01 | Population is complete | Reconcile input and output counts | Control summary |
| CTL-02 | Only active, approved rules are used | Validate rule status before application | Reference report |
| CTL-03 | Exceptions are visible, not buried | Review exception output | Exception register |
| CTL-04 | Summary is traceable to detail | Tie summary to detail | Tie-out report |
| CTL-05 | Review was actually performed | Confirm review status per item | Decision log |
