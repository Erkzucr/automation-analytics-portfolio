# Data Dictionary

| Field | Meaning | Example |
|---|---|---|
| record_id | Unique key, used as the match key between the two sides | REC00001 |
| period_key | Period being reconciled | P01 |
| dimension_a | Grouping attribute carried through the match | DA001 |
| dimension_b | Secondary grouping attribute | DB001 |
| category_code | Category used to route match breaks | CAT01 |
| value_amount | Synthetic value compared across both sides | 1250.00 |
| status_code | Match or review status | VALID |
